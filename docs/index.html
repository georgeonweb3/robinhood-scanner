Robinhood Chain Safety Scanner

Paste a contract. Get CLEAR / CAUTION / BLOCKED / UNKNOWN with receipts. Read-only, never signs, never asks for a key. Sellability is not faked, see the note in every report.
How it works / limits: this whole scan runs from your own browser. The page makes read-only JSON-RPC calls straight from your device to the Robinhood Chain RPC and to Blockscout, there is no scanner server in between. If your network, the RPC, or Blockscout blocks or fails a call, the verdict says UNKNOWN or "could not check" for that item, never a made-up negative: a failed read is evidence about the network, not about the contract. A CLEAR means nothing this scanner checks tripped. It is not a guarantee and not an audit.
Free basic scan. Pro (in the works): unlimited scans, new-pool alerts, history.
